# بررسی کامل پروژه AdBlock Pro IR

## خلاصه معماری

افزونه Chrome (Manifest V3) برای حذف تبلیغات در سایت‌های ایرانی (آپارات، فیلیمو، نماوا، روبیکا و...).

### ساختار فایل‌ها
```
├── manifest.json          ← Manifest V3 config
├── background.js          ← Service worker (storage, messaging, rules)
├── content.js             ← Content script entry point
├── core/
│   ├── constants.js       ← Selectors, patterns, defaults
│   ├── storage.js         ← Chrome storage wrapper
│   └── domUtils.js        ← DOM utility functions (UNUSED)
├── utils/
│   ├── logger.js          ← Logger with DEBUG flag
│   └── messaging.js       ← Chrome runtime message wrapper
├── platforms/
│   ├── base.js            ← Base class for all platforms
│   ├── global.js          ← Cross-site banner ad hiding
│   ├── aparat.js, filimo.js, namava.js, rubika.js, ...
├── popup/
│   ├── popup.html/js/css  ← Extension popup UI
│   └── components/
│       ├── stats.js       ← Counter display
│       └── toggle.js      ← Settings toggles
├── rules/rules.json       ← DeclarativeNetRequest rules
├── styles/injected/       ← (empty or injected styles)
├── fonts/                 ← Vazirmatn font
└── icons/                 ← Extension icons
```

### جریان کار
1. **background.js**: مدیریت storage، اعمال قوانین declarativeNetRequest، پاسخ به پیام‌ها
2. **content.js**: بارگذاری تمام پلتفرم‌ها، راه‌اندازی MutationObserver
3. **platforms/*.js**: هر پلتفرم بررسی تبلیغات ویدیویی و بنری مخصوص خودش
4. **popup/**: نمایش آمار و تنظیمات

## مشکلات پیدا شده

### 1. [بحرانی] شمارنده تبلیغات رد شده هیچ افزایش نمی‌یابد

**مشکل اصلی**: `skippedCount` همیشه ۰ است.

**علت**: پلتفرم `GlobalPlatform` (که روی تمام سایت‌ها اجرا می‌شود) تبلیغات بنری را مخفی می‌کند ولی **هیچ‌وقت شمارنده را افزایش نمی‌دهد**.

فایل `platforms/global.js:22-37` — متد `_scanDOM()`:
```js
// تبلیغ مخفی می‌شود ولی _reportSkip() صدا زده نمی‌شود
if (blocked) {
  el.dataset.adblockHidden = '1';
  el.style.setProperty('display', 'none', 'important');
  // ❌ اینجا باید this._reportSkip() فراخوانی شود
}
```

**تاثیر**: چون بنرها رایج‌ترین نوع تبلیغ هستند و شمارش نمی‌شوند، عدد شمارنده تقریباً همیشه صفر باقی می‌ماند.

**راه‌حل**: اضافه کردن `this._reportSkip('banner-hide')` در `_scanDOM()` وقتی تبلیغی مخفی می‌شود. برای جلوگیری از شمارش تکراری، از `el.dataset.adblockHidden` استفاده می‌شود (که قبلاً هم ست شده).

---

### 2. [متوسط] عدم تطابق کلاس CSS بج (Badge)

فایل `popup/components/toggle.js:53`:
```js
UI.statusBadge.className = 'badge ' + (enabled ? 'badge-active' : 'badge-inactive');
```

ولی در `popup/popup.css` کلاس‌ها `badge--on` و `badge--off` تعریف شده‌اند:
```css
.badge--on { ... }
.badge--off { ... }
```

**نتیجه**: وقتی افزونه فعال/غیرفعال می‌شود، رنگ بج تغییر نمی‌کند.

**راه‌حل**: تغییر `badge-active` → `badge--on` و `badge-inactive` → `badge--off` در toggle.js.

---

### 3. [متوسط] فایل `domUtils.js` استفاده نمی‌شود

فایل `core/domUtils.js` تعریف شده ولی هیچ‌جا import/استفاده نمی‌شود. همچنین از `async/await` استفاده می‌کند در حالی که بقیه پروژه از ES5-compatible syntax استفاده می‌کند.

**راه‌حل**: حذف فایل `domUtils.js` و حذف ارجاع از manifest (اگر وجود داشته باشد).

---

### 4. [متوسط] تکرار مقداردهی اولیه `DEFAULTS`

- `core/constants.js` → `DEFAULTS` (خط 9-14)
- `background.js` → `DEFAULTS_BG` (خط 47-52)

هر دو دقیقاً یکسان هستند. تغییر در یکی ممکن است فراموش شود در دیگری اعمال شود.

**راه‌حل**: استفاده از `DEFAULTS` در background.js (نیاز به import یا ارجاع به constants).

---

### 5. [کم] پلتفرم‌های خالی بدون تشخیص تبلیغ

`SheydaPlatform`, `MyketPlatform`, `TmkPlatform` فقط constructor دارند و هیچ `checkVideoAd` یا `applyBannerStyles` override نکرده‌اند. این یعنی:
- تبلیغات ویدیویی با الگوی پیش‌فرض base.js بررسی می‌شوند (ممکن است خیلی محدود باشد)
- تبلیغات بنری فقط توسط GlobalPlatform مخفی می‌شوند

---

### 6. [کم] شمارش تکراری شمارنده

وقتی `NamavaPlatform._seekToEnd()` یا `TelewebionPlatform._tryClickSkip()` با poll interval فراخوانی می‌شوند، ممکن است `_reportSkip()` چند بار فراخوانی شود. البته برخی پلتفرم‌ها (مثل Namava) از `dataset.adblockSkipped` استفاده می‌کنند ولی `_reportSkip()` قبل از چک کردن این dataset فراخوانی می‌شود.

در `base.js:71-90` — `skipVideo()`:
```js
if (video.dataset.adblockSkipped) return false;  // ← چک بعد از ورود
// ... انجام skip ...
video.dataset.adblockSkipped = '1';               // ← ست کردن
this._reportSkip('video-seek');                    // ← گزارش
```

این درست است. ولی در `namava.js:56`:
```js
this._reportSkip();  // ← بدون ارسال method
```

و `telewebion.js:35` و `:46` هم `_reportSkip` را فراخوانی می‌کنند. اگر poll چند بار اجرا شود و `_reportSkip` قبل از ست شدن `adblockSkipped` فراخوانی شود، شمارنده تکراری افزایش می‌یابد.

**راه‌حل**: اضافه کردن چک `video.dataset.adblockSkipped` قبل از فراخوانی `_reportSkip()` در metohd‌هایی که خودشان `_reportSkip` صدا می‌زنند (نه از طریق `skipVideo()`).

## فایل‌هایی که نیاز به تغییر دارند

| فایل | تغییر |
|------|--------|

## روش تست

1. نصب افزونه در Chrome
2. باز کردن سایت آپارات یا هر سایت با تبلیغ بنری
3. بررسی اینکه `skippedCount` افزایش یافته
4. بررسی تغییر رنگ بج با فعال/غیرفعال کردن افزونه
5. ریست کردن آمار و بررسی بازگشت به صفر
